# AI-Powered Workplace Productivity Assistant

## Project Overview

An AI-assisted prototype designed to reduce repetitive workplace tasks through email drafting, meeting-note summarization, and task planning.

## Features

- **Smart Email Generator:** Draft professional emails with different tones and audiences.
- **Meeting Notes Summarizer:** Extract key points, decisions, action items, responsibilities, and deadlines from supplied notes.
- **AI Task Planner:** Organize daily or weekly tasks, prioritize by urgency and importance, and suggest time-management improvements.

## Responsible AI

Review generated content before use. Avoid entering confidential or sensitive workplace information without authorization. Verify summaries, decisions, deadlines, and task assignments because AI outputs can contain errors.
